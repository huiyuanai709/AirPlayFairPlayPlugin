# AirPlayFairPlayPlugin

Out-of-tree **native** FairPlay media-key plugin for [AirPlayServer.NET](https://github.com/huiyuanai709/AirPlayServer.NET).

- License: **GPL-3.0** (PlayFair). Do **not** link this into the MIT Native AOT host.
- Load at runtime: `AirPlayServer.Host --media-key-plugin path\to\AirPlayFairPlayPlugin.dll`
